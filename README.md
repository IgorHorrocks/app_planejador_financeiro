# Organizador Financeiro

Aplicação web para organização financeira pessoal e planejamento de aposentadoria.

O sistema permite acompanhar:

- Receitas
- Despesas fixas e variáveis
- Parcelas
- Investimentos e reservas
- Evolução patrimonial
- Meta e projeção de aposentadoria

## Dados e privacidade

Os dados financeiros são armazenados no **OneDrive do próprio usuário**, por meio do login com conta Microsoft.

O aplicativo utiliza um arquivo privado chamado:

`organizador_financeiro.json`

Não há banco de dados central com as informações financeiras dos usuários.

## Acesso

Aplicação desenvolvida em HTML, CSS e JavaScript, com interface responsiva para computador e celular.
